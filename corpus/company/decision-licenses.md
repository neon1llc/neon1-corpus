# Decision: a license for each repository

I say "public code and resources," not "open source," because not every repository is open source.

## What I chose

| Repositories | Code | Written content |
|---|---|---|
| neon1-site, neon1-corpus, neon1-chat, neon1-aws-infrastructure | Functional Source License 1.1, converting to Apache 2.0 | CC BY-ND 4.0 |
| neon1-1NEON | MIT | Same repository |
| deploy-ops | Apache 2.0 | Same repository |
| aws-clip, refmark | MIT | Same repository |
| Education repositories | MIT | CC BY-SA 4.0 |

GitHub's license detection shows "none" for several of these because the files are dual or custom, so the LICENSE files are the source.

## What each one allows

The Functional Source License lets anyone read and run the code, and bars using it to compete with neon1 for two years, after which each release becomes Apache 2.0. MIT and Apache 2.0 allow reuse, including commercial use. CC BY-ND 4.0 allows sharing the text unchanged, and CC BY-SA 4.0 allows adapting it under the same license.
